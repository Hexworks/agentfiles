# Use a table component when viewing tabular data

Currently when existing profiles are listed they are displayed in a tabular format, but the content is misaligned and looks ugly in general. Let's use a table component that was made for displaying tabular content. The libraries that we use should contain this. If not let's look for one or implement one.
