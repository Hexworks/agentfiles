# Extract all text labels and use an i18n tool to handle them

We hard-code UI labels and texts right now. We need to move all these out of the rendering logic and into some i18n utility.

**Important**: we haven't chosen this utility yet, let's look for the best option that is a best practice in Go.

Whenever we do this task this research should be part of the task and we should make a decision after we do the search.
