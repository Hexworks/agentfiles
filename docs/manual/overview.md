# agentfiles — Overview

`af` is a TUI for managing AI-assistant profiles and projecting them into target
repositories. A profile owns the canonical skills, hooks, MCP entries, and rules;
`af` renders the selected assets into managed surfaces in each linked project.
Press `?` from any screen to reopen this page.

## Global keys

- `n` — Notifications
- `s` — Settings
- `?` — Help
- `q` / `ctrl+c` — Quit
