# agentfiles — Overview

`af` is a TUI for managing AI-assistant profiles and projecting them into target
repositories. A profile owns the canonical skills, hooks, MCP entries, and rules;
`af` renders the selected assets into managed surfaces in each linked project.

This page is the Welcome screen's help. Press `?` on any other screen to open
the page that describes the operations available there.

## Welcome menu

- `↑`/`k` and `↓`/`j` — move the cursor
- `enter` / `v` — choose the highlighted row
- Rows: **Profiles** (manage profile registry), **Settings**, **Quit**

## Global keys

- `n` — Notifications log
- `s` — Settings
- `?` — Help (this page on Welcome, screen-specific elsewhere)
- `q` / `ctrl+c` — Quit
